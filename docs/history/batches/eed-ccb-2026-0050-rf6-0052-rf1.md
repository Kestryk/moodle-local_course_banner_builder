# EED-CCB-2026-0050 RF6 / EED-CCB-2026-0052 RF1

## Scope

This source-only lot closes two narrow administration presentation defects:

- Image Layer infos cells follow the containing row's rest, hover and focus
  surfaces. Border and overlay semantic row tints remain owned by their row
  classes. The disclosure summary uses two bounded columns with safe wrapping,
  so labels and values cannot overlap at narrow widths or browser zoom.
- Course and Site manager Source Preview side-panel buttons keep a fixed
  action height. The right panel stretches through the remaining layout width
  and uses a compact gap after the preview canvas.

No runtime, browser, preview, fixture or cache activity is part of this lot.

## Evidence

- `classes/manager.php` preserves the existing border/overlay style mapping;
  unlocked Image row surfaces are normalised by the row-state CSS contract.
- `_action-contract.scss` bounds disclosure columns and enables safe wrapping.
- `_admin-controls.scss` fixes side-panel action button height.
- `_admin-layout.scss` keeps the right panel stretched and reduces the preview
  to panel gap for Course/Site manager.
- `styles.css` is the generated official Sass artifact.

## Acceptance gate

Run the focused static contracts and review the managed preview at desktop,
narrow width and genuine zoom before marking this lot human-validated.
