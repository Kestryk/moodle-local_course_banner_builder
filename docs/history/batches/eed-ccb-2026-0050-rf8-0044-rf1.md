# EED-CCB-2026-0050 RF8 / EED-CCB-2026-0044 RF1

## Scope

This source-only corrective lot follows the Wave 6 human review:

- an unlocked Image row must give its Layer infos & overrides cell exactly the
  same rest, hover and focus surface as every sibling cell;
- closing Layer infos & overrides must slide continuously to its native closed
  state, without a short plateau immediately before the content disappears.

Previously accepted long-value wrapping, help spacing, Border/Overlay semantic
surfaces and the Course/Site preview-panel geometry remain unchanged.

## Implementation

The Image override cell no longer has its own `!important` surface rules.
Since the obsolete PHP inline Image tint was removed in RF7, the row's direct
cell rule is now the sole owner. This also lets a Moodle theme apply one
consistent table hover state rather than changing every cell except Layer
infos.

The Layer infos content wrapper now has zero padding. The same accepted spacing
is carried by its direct children. A padded border-box has a non-zero visual
floor during a height-to-zero Web Animation; removing that floor lets the
existing `Motion.collapse` finish smoothly. No JavaScript timing, state,
interruption or reduced-motion behavior is changed.

## Validation evidence

The dedicated source worktree passed:

- the focused Layer info / preview-panel contract;
- the official Sass build for `styles.css`;
- module-mode parsing of the unchanged accordion controller and Motion source;
- PHP lint and `git diff --check`.

The Sass build completed with Dart Sass 1.89.2. Its existing `@import` and
mixed-declaration deprecation warnings remain outside this correction.

No Moodle runtime, cache purge, fixture mutation, browser, screenshot or
managed-preview action belongs to this source-owner lot. The integration owner
must promote the clean pushed commit before human visual review.
